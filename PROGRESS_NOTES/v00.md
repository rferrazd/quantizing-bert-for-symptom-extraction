# Version 0.0

## General Notes

* Fine-tuned **DistilBERT** with 3 hyperparameter variations
    * once training all layers (on accident)
* Fine-tuned **BioBERT** twice:

  * once training all layers
  * once training only the token-classification head

In all experiments, performance was similar:

* **F1 ≈ 0.0**
* **Accuracy ≈ 0.5**

Freezing or unfreezing the backbone **did not change results**, indicating the issue was not optimization-related.

---

## Dataset v0.0

* Token-level NER with BIO tagging
* Label format:

  ```
  {B|I}_SYMPTOM_{concept_id}_{POLARITY}
  ```

  Example:

  ```
  B-SYMPTOM_s0004_NEG
  ```

### Label Statistics

* Total labels (excluding `-100`): **3525**
* Each label appears **~10 times total**
* Majority class: **"O"**

```
Unique label ids (incl. -100): 3526
Max label id (excl. -100): 3524
model.config.num_labels: 3525
```

Example distribution (first labels):

```
{-100: 35720, 0: 10, 1: 10, 2: 10, ..., 28: 10}
```

---

## Why v0.0 Did Not Work

* Extreme **label sparsity**: each label has ~10 examples
* Very **large label space** (3525 classes) for token classification
* No parameter sharing between symptom concepts
* Strong **class imbalance** toward `"O"`

As a result, models converge to predicting `"O"` for most tokens:

* Accuracy remains ~0.5
* Precision, recall, and F1 collapse toward 0

This behavior was consistent across:

* DistilBERT vs BioBERT
* Frozen vs fully trainable backbones

---

## Notes on Training

* BioBERT training completed quickly (~10 minutes on a single NVIDIA T4)
* Fast convergence further suggests the model learned a trivial solution
  (predicting `"O"`), rather than meaningful symptom representations
